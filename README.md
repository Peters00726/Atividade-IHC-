# 🖥️ Atividade de IHC — Interação Humano-Computador

**Projeto acadêmico | Análise e Desenvolvimento de Sistemas**

## 📌 Sobre o projeto

Este repositório reúne atividades acadêmicas desenvolvidas na disciplina de **Interação Humano-Computador (IHC)**, área da computação dedicada ao estudo e ao desenvolvimento da interação entre pessoas e sistemas computacionais.

O objetivo é aplicar conceitos de usabilidade, acessibilidade e design de interação para compreender como as interfaces digitais podem proporcionar experiências mais intuitivas, eficientes e satisfatórias aos usuários.

## 🎯 Objetivos

- Compreender os fundamentos da Interação Humano-Computador.
- Analisar interfaces e identificar possíveis problemas de usabilidade.
- Aplicar princípios de design centrado no usuário.
- Explorar técnicas de prototipação e avaliação de interfaces.
- Desenvolver uma visão crítica sobre a interação entre usuários e sistemas digitais.

## 🧠 Principais conceitos

### Usabilidade
Avalia a facilidade com que os usuários conseguem utilizar um sistema para atingir seus objetivos.

### Experiência do Usuário (UX)
Considera as percepções, necessidades e experiências das pessoas durante a utilização de um produto ou serviço.

### Interface do Usuário (UI)
Abrange os elementos visuais e interativos que permitem a comunicação entre o usuário e o sistema.

### Acessibilidade
Busca tornar sistemas e interfaces utilizáveis por pessoas com diferentes habilidades e necessidades.
